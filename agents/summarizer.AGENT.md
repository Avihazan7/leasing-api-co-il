# Summarizer — מפרט סוכן (AGENT.md)

> סיכום מסמך בסיכום מעוגן-מקור. זהו הסוכן הראשון שמומש בפועל — ראו `stage-a/src/worker-summarizer.js`. מפרט זה מתעד את החוזה שהקוד כבר ממש.

## 1. זהות

| שדה | ערך |
| --- | --- |
| `id` | `summarizer` |
| שם תצוגה | Summarizer |
| פרופיל | `legal` |
| גרסה | 1.0.0 |

## 2. תחום אחריות

מסכם מסמך יחיד לרשימת נקודות, כשכל נקודה מעוגנת בשורת מקור. **אינו** מתכנן (תפקיד המנהל), **אינו** משווה בין מסמכים (תפקיד עתידי), **אינו** מסיק מסקנות משפטיות — רק מתמצת את מה שכתוב.

## 3. חוזה קלט

- `inputRef`: `source:<id>` (מסמך גולמי) או `step:<id>` (תוצר סיכום קודם).
- מבנה צפוי: `{ clauses: [{ id, text, gist }] }`.
- `dependsOn[]`: ריק כשהקלט הוא מקור גולמי.

## 4. חוזה פלט

`worker-output` עם `payload`:

```jsonc
{
  "status": "complete" | "partial",
  "flags": [],
  "summary": [ { "point": "...", "evidence": { "kind": "source-line", "ref": "c1", "quote": "..." } } ]
}
```

`evidence[]` = רשימת העוגנים של כל הנקודות. חובה ולא-ריק. תוצר `partial` נושא עדות מסוג `missing-input`.

## 5. כללי התנהגות

- כל נקודת סיכום מצרפת `evidence` המפנה לשורת המקור (`clause.id` + ציטוט מלא).
- אין להמציא תוכן שאינו קיים במקור.
- הסיכום דטרמיניסטי: כל סעיף מקור הופך לנקודה אחת.

## 6. עקרונות-העל

| עיקרון | יישום |
| --- | --- |
| ביסוס | כל נקודה נושאת `{ kind: 'source-line', ref, quote }`. |
| עצירה בטוחה | קלט שלא נפתר → `status: 'partial'`, `flags: ['incomplete-source']`. |
| שקיפות | התוצר נכתב לזיכרון המשותף append-only. |
| חיסיון | מאגר המקורות מקומי, אפס תלות חיצונית. |
| אדם-בפיקוד | תוצר `partial` מיועד לסקירת אדם. |

## 7. עצירה בטוחה ושער אנושי

- **קלט חסר** (`source`/`step` לא נפתר) → תוצר `partial` + דגל `incomplete-source`, ללא קריסה.
- **שער אנושי**: כל תוצר `partial` עובר לסקירה לפני שימוש במורד הזרם.
- פועל בתוך תקרת הצעדים של המנהל; אינו מזמן את עצמו.
