## 1. מחירון — עמלות עסקה (לפי D-015)

| סוג עסקה | עמלה | מי משלם | מתי |
|-----------|------:|----------|------|
| **B2B** — ספק ↔ עסק / צי / ליסינג | **1.1%–2.2%** מערך העסקה | הספק המוכר | רק על עסקה שנסגרה |
| **B2B2C** — עסקה לקונה דרך הפלטפורמה (עסקי) | **1.1%–3.33%** | הצדדים לעסקה | רק על עסקה שנסגרה |

**עקרון הברזל:** אפס עלות הצטרפות · אפס דמי רישום · אפס מינימום — משלמים רק על הצלחה.

## 3. מחירון — מנויי B2B: Ultra מול Max

> למי: דילרים, מפיצים, חברות ליסינג קטנות. חיוב חודשי, ללא התחייבות · **−10% בהתחייבות שנתית** (D-020).

| יכולת | **Ultra** — ₪4,500/חודש | **Max** — ₪7,700/חודש |
|--------|:---:|:---:|
| גישה מלאה לקטלוג + חיפוש מתקדם | ✅ | ✅ |
| **מידע וניתוחים מתקדמים** — מחירי שוק, מגמות 0 ק"מ/גיולים, דוחות שבועיים | ✅ | ✅ |
| **Deal Score** לכל רכב בקטלוג | ✅ | ✅ |
| **גישה למכרזים מיבואני רכב** — צפייה + התראות בזמן אמת | ✅ | ✅ |
| השתתפות במכרזי כמויות (מחיר-שני) | עד **2**/חודש | **ללא הגבלה** |
| **עסקאות בכמויות (bulk) און-ליין** | — | ✅ |
| חדר-עסקה מרוכז לרכישות מרובות | — | ✅ |
| גישת **API / Data-feed** ישירה למערכות הקונה | — | ✅ |
| עדיפות בהקצאת מלאי חדש | — | ✅ |
| מנהל לקוח ייעודי + תמיכה מועדפת | — | ✅ |
| משתמשים בחשבון | 2 | 5 |

**כלל מעבר:** מנוי Ultra שמבצע 3+ עסקאות כמות בחודש — משתלם לו לעבור ל-Max. המערכת מתריעה אוטומטית.

> 📌 **שלבים:** ב-Phase 0 (השקה) נמכר **Ultra בלבד**; Max נפתח ב-Phase 1 יחד עם מכרז הכמויות (M7) — לפי `ULEASE_SPEC.md` §12.

## 4. SLA ספקים — אמנת השירות

> מגבה את ההבטחות שכבר ניתנו ב-playbooks: *"אנחנו עושים את האינטגרציה"*, *"שקיפות והתחשבנות בזמן אמת"*, *"תוך 48 שעות תראה ביקוש"*. כל הזמנים בשעות/ימי **עסקים**. כל הערכים אושרו ע"י המייסד (D-020).

| # | פרמטר שירות | התחייבות | אם לא עמדנו |
|---|--------------|-----------|--------------|
| 1 | **חיבור ראשוני (onboarding)** — API או CSV | ≤ **48 שעות** מקבלת הנתונים — אנחנו מבצעים את האינטגרציה | — |
| 2 | **עליית מלאי לקטלוג (ingestion)** — API | ≤ **4 שעות** | — |
| 3 | **עליית מלאי — CSV ידני** | ≤ **24 שעות** | — |
| 4 | **דמו ביקוש לפיילוט** ("שלח 10 רכבים") | ≤ **48 שעות** — דוח ביקוש ראשוני | הארכת הפיילוט בשבוע, חינם |
| 5 | **העברת ליד לספק** (לאחר הסכמת קונה) | ≤ **1 שעה** | הליד חינם |
| 6 | **זמינות פלטפורמה (uptime)** | **99.5%** ב-Phase 0 → יעד **99.9%** מ-Phase 1 (לפי NFR) | זיכוי יחסי בעמלות החודש |
| 7 | **דוח התחשבנות** (עסקאות, לידים, עמלות) | זמין **בזמן אמת** בלוח הספק + סיכום חודשי עד ה-3 לחודש | — |
| 8 | **העברת מקדמה לספק** (כשהמקדמה עוברת דרך הפלטפורמה) | ≤ **T+3 ימי עסקים** מהחתימה | — |
| 9 | **חיוב עמלות** | בתחילת החודש העוקב, מנוכה/מחויב לפי הדוח | — |
| 10 | **תגובה לתקלה קריטית** (מלאי לא עולה / חדר-עסקה מושבת) | ≤ **2 שעות** | — |
| 11 | **תגובה לפנייה רגילה** | ≤ **1 יום עסקים** | — |

**מה אנחנו מבקשים בתמורה (חובות הספק):**
- מלאי מעודכן: זמינות ומחיר נכונים (עדכון ≤ 24 שעות מ-שינוי).
- מחיר רצפה אמיתי — אין "מחירי פיתיון" בקטלוג.
- מענה לפניות קונים שהועברו: ≤ 1 יום עסקים.
