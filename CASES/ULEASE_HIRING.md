## תפקיד 1 — מנהל מערכות טכנולוגיה (Founding Tech Lead)

### א. תמצית התפקיד
לבעלות מלאה על הטכנולוגיה של ULease מקצה-לקצה: **התקנה, חיבור, השקה ותחזוקה** של האתר והאפליקציה, חיבורי הספקים (APIs), ומנוע ה-**Multi-agent Ultra·Master·Max**.
**כפיפות:** אברהם (מו"פ/מוצר) + שירי (COO). **התחלה:** מיידית — MVP לאוויר תוך ~שבועיים.

### ב. אחריות (Responsibilities)
- העלאת האתר/אפליקציה לאוויר + חיבור `Leasing.co.il` ↔ `ULease.co.il` (hosting, דומיינים).
- **Ingestion מספקים:** APIs + נפילה-לאחור ל-CSV, נרמול מלאי.
- **חדר-עסקה:** חתימה דיגיטלית + תשלום/מקדמה + handoff למימון/ליסינג.
- מנויים וחיוב חוזר (Ultra / Max).
- מימוש מנוע הסוכנים: **Ultra** (orchestration) · **Master** (Match/Pricing/Negotiation) · **Max** (ביצוע) — להתחיל ב-assist.
- אבטחה, guardrails, monitoring, audit; הוצאת MVP ל-production יציב.

### ג. דרישות
**חובה (Must-have):**
- יכולת **shipping מלאה** — לבנות ולהעלות web + app מהר.
- אינטגרציות **API/Webhooks** ואוטומציה (n8n/Make או קוד).
- ניסיון/יכולת מהירה ב-**LLM/Agents** — Claude API/Agent SDK, orchestration, RAG, vector DBs.
- Cloud/hosting, CI/CD, יסודות אבטחה (תשלומים/PII).
- עברית + אנגלית · ראש startup · בעלות ומהירות.

**יתרון (Nice-to-have):**
- דומיין Marketplace / fintech / רכב.
- ניסיון ב-e-signature / תשלומים / KYC.
- DevOps ו-scalability.

### ד. מה מציעים
- **Impact של מייסד** — לבנות מאפס stack סוכנים בקצה הטכנולוגיה.
- מודל מתודולוגי ייחודי (תורת המשחקים · Big Five · מו"מ).
- **תגמול (נעול, D-069):** משרה מלאה · **חבילה היברידית** — שכר מופחת **~₪20K–28K** ברוטו/חודש + **אקוויטי/profit-share של מייסד-מוקדם** (טווח מוצע 3%–6%, vesting 4 שנים / cliff שנה — לסגירה סופית מול רו"ח+עו"ד, תואם D-003 ו-`ULEASE_LEGAL_BRIEF`). המסר: *"שכר שמכבד + נתח אמיתי בחברה שאתה בונה."*

## ו. שאלות ראיון (תפורות ל-ULease)

**1 · Shipping ואינטגרציות**
- ספק נותן feed מלאי לא-עקבי (API או CSV). איך מנרמלים ומעלים לקטלוג **תוך יום**?
- איך היית מחבר **חתימה דיגיטלית + מקדמה + handoff למימון** בחדר-עסקה? אילו שירותים?
- יש שבועיים ל-MVP — מה עולה לאוויר ביום 14, ומה נדחה?

**2 · סוכנים ו-LLM**
- איך תבנה **orchestrator** שמנתב event (ליד) לסוכני מומחיות? איך מנהלים state וזיכרון?
- מתי **RAG** נחוץ כאן, ואיזה vector DB תבחר — ולמה?
- איך מטמיעים **guardrails + human-in-the-loop** לסוכן שמבצע פעולה אמיתית (חוזה/תשלום)?

**3 · ארכיטקטורה ואבטחה**
- איך תאבטח **PII ותשלומים**? מה דורש תשומת-לב רגולטורית בישראל?
- איך תתכנן את המערכת לעמוד בעומס **מכרזים מקבילים**?

**4 · התאמה ובעלות**
- ספר על משהו שהעלית לאוויר **לבד**, מקצה-לקצה.
- איך אתה עובד מול founder לא-טכני (אברהם) ו-COO (שירי)?

**5 · משימה מעשית (Take-home קצר / לוח)**
- עצב את הצינור **ingestion → listing → lead** + סוכן **Match ב-assist**. דיאגרמה + הבחירות הטכנולוגיות.

**🟢 דגלים ירוקים:** מעלה מהר, שואל על העסק לא רק על הטק, מדבר trade-offs, מכיר agent patterns.
**🔴 דגלים אדומים:** over-engineering, "צריך 6 חודשים ל-MVP", לא נגע באינטגרציות אמיתיות, בורח מבעלות.
