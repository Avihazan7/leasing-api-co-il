## 1. המודל — איך ULease משתלבת (קריטי)

ULease היא ה**רכבת הדיגיטלית** שמנתבת את לקוח הקצה ל**שותפים מורשים** שמבצעים את החיתום/הקשירה המוסדרים. ULease **לא** מלווה ולא מבטחת בעצמה (שלב 1) — היא מתאימה, מנתבת, מאחדת ומרוויחה עמלות.

```
לקוח קצה → חדר-עסקה ULease → חיתום דיגיטלי → שותפים מורשים (מימון·ליסינג·ביטוח)
                              (KYC · ניתוב · באנדל)        ↓
                                                    החלטה + תנאים → חתימה
```

## 2. צד השותפים — Value Prop + החתמה

| שותף | מה הוא מקבל מ-ULease | מה ULease מקבלת |
|------|----------------------|------------------|
| **חברת מימון** | זרם בקשות מימון איכותיות, מסוננות ו-pre-qualified | עמלת origination לעסקה |
| **חברת ליסינג (מימוני)** | לקוחות מוכנים-לחתימה, דיגיטלי | עמלה לעסקה |
| **חברת ביטוח / סוכנות** | פוליסות חדשות בנקודת המכירה | עמלת סוכן/referral |
| **שירותי דרך** | מנויים נלווים לכל רכב | referral / קידום |

**הקרס (Hook):** *"אנחנו מביאים לך לקוח **בנקודת ההחלטה** — אחרי שבחר רכב, עם נתונים מסוננים ו-KYC. אתה מקבל בקשה איכותית ומוכנה-לחיתום, לא ליד קר."*

**פיילוט:** חבר API/טופס · נתב אליו X בקשות/חודש · עמלה רק על מה שנחתם.

## 3. ⚙️ החיתום הדיגיטלי — הזרימה מקצה-לקצה (הלב)

| # | שלב | מה קורה |
|---|-----|----------|
| 1 | **לכידת נתונים + KYC** | ת"ז, אימות זהות, הכנסה/תעסוקה, התחייבויות קיימות |
| 2 | **הסכמות** | אישור לבדיקת נתוני אשראי (דרך **לשכת אשראי מורשית**) ושיתוף מידע |
| 3 | **חיתום מימון** | שליחה לשותף(ים) מורשים ב-API → החלטה מהירה → תנאים (ריבית, תקופה, החזר) |
| 4 | **ניתוב רב-מלווה** | שליחה ל**מספר** מממנים → **ההצעה הטובה ביותר** ללקוח (תחרות) |
| 5 | **חיתום ביטוח** | נתוני רכב+נהג → הצעת ביטוח → קשירת פוליסה ע"י **סוכן מורשה** |
| 6 | **באנדל שקוף** | מחיר רכב + מימון + ביטוח + שירותי דרך → **החזר חודשי אחד** |
| 7 | **חתימה דיגיטלית + הפעלה** | חוזה, מקדמה, הפעלת פוליסה — הכול דיגיטלי |
| 8 | **Guardrails** | הוגנות, שקיפות מלאה, פרטיות (חוק הגנת הפרטיות) |

> ⚡ הערך ללקוח: מ"בחרתי רכב" ל"מאושר עם מימון וביטוח" ב**דקות**, עם **מספר אחד שקוף** — לא שבועות של רדיפה.

## 4. ניתוב רב-מלווה + תורת המשחקים

הבקשה נשלחת ל**מספר** מממנים שמתחרים על הלקוח → הלקוח מקבל את התנאים הטובים ביותר.
**Win-Win:** הלקוח חוסך, המממנים מקבלים לידים איכותיים, ULease מרוויחה origination. אותו עיקרון של **מכרז מחיר-שני** — מהצד של הביקוש.

---

## 5. התאמה אישית (Big Five) — איזה מבנה להציע

| פרופיל | מבנה מימון/ביטוח מומלץ |
|--------|-------------------------|
| **N↑** (חרד) | ביטוח מקיף, ריבית קבועה, הגנת תשלומים, הרגעה |
| **N↓** (בטוח) | רזה ומהיר, פחות תוספות |
| **C↑** (מתכנן) | TCO מלא (כולל מימון+ביטוח), שקיפות, השוואה |
| **A↓** (סוחר) | הצג את **תחרות המממנים** והריביות בשקיפות |

> 🛡️ אתיקה (Guardian): אסור לנצל חרדת `N↑` למכירת-יתר. ההתאמה משרתת את הלקוח, לא מנצלת.

## 6. מודל הכנסה (מחזק את הזרם השישי)

- **מימון/ליסינג (D-015):** **1% מערך העסקה** (≈₪1,500 על עסקה ממוצעת) — משולם ע"י **חברת המימון** על כל עסקה ממומנת.
- **ביטוח:** עמלת סוכן/referral לפוליסה (טרם ממודל בתחזית — upside).
- **שירותי דרך:** referral.
- **פרסום/קידום:** דמי מיקום מחברות מימון/ביטוח.

> 💡 **בתחזית:** עמלת המימון ממודלת כשורת `fin_rev` ב-`ULEASE_FORECAST.csv` — 1% × ₪150K × הנחת 50% attach ≈ **₪750/עסקה** משוקלל, פעיל מספטמבר 26.
