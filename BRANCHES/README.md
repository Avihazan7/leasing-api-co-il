# BRANCHES/ — ספרי הידע של הסניפים

> תיקיית ה-memory של שכבת הקצה. כל סניף/סוכנות של ULease מחזיק כאן קובץ אחד —
> ספר הידע שלו. הדוקטרינה המלאה: [`../BRANCH_KNOWLEDGE.md`](../BRANCH_KNOWLEDGE.md).

## איך פותחים סניף חדש

1. מעתיקים את [`_TEMPLATE.md`](./_TEMPLATE.md) → `<שם-הסניף>.md` (באנגלית, kebab-case: `tel-aviv.md`, `haifa-north.md`)
2. ממלאים את § 1 (פרופיל) — 10 דקות, לא יותר
3. פותחים ערוץ Slack פרטי: `#branch-<שם>-private`
4. מגדירים ב-n8n את ה-routing של הסניף (W4/W5 לפי `dealer_id` — ראה `BRANCH_KNOWLEDGE § 4.1`)

| כלל | פירוט |

| **בלי PII** | אין שמות לקוחות, ת"ז, טלפונים. רק דפוסים. `/scrub-pii` לפני commit |

| **Append, לא rewrite** | לקחים לא נמחקים — מסומנים `[בוטל]` אם התבדו. היסטוריה = ידע |
| **מי כותב** | W6 (אוטומטי, שבועי) או Tech Lead. סוכנים כותבים בערוץ הפרטי, לא כאן |
